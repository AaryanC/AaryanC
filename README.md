### Built

**8-Bit Computer from Scratch** &nbsp;|&nbsp; *Digital logic · PCB design · Assembly*  
A working 8-bit computer on a custom-designed PCB, with its own terminal, OS, and GUI. I designed it from logic gates up to software, so I know exactly what the machine does with every instruction.  
[Repository](LINK)

**Schism: Game and Custom Physics Engine** &nbsp;|&nbsp; *C# · Unity*  
A game built to support focus in students with ADHD. It has a hand-written physics engine and custom shaders, and the Unity editor is extended with enemy AI and **real-time adaptive difficulty driven by a PID controller**, tuned through beta testing with 15+ players. Previously released on Steam.  
[Repository](LINK)

**FRC Autonomous Robot** &nbsp;|&nbsp; *Java · PhotonVision*  
I was head programmer for a 23-member team. I wrote the vision-guided autonomous routines and driver control for a robot launching game pieces at 20 m/s, where real-time decisions had to work reliably under competition conditions.  
[Repository](LINK)

**Stray9** &nbsp;|&nbsp; *Mobile · Google Maps · Vision AI*  
An app connecting volunteers with stray dogs that need help across Mumbai, built in partnership with the city's municipal corporation (BMC).  
*Source code is private.*

**AI-Enabled Educational Stethoscope** &nbsp;|&nbsp; *Embedded systems · NFC · DAC*  
A training device that synthesizes disease-specific heart and lung sounds for medical students, built with faculty mentorship from the University of Zaragoza, Spain.  
*Source code is private at the request of project sponsors.*
